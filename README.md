# Padaria Vitória

Sistema web desenvolvido para a Padaria Vitória, com o objetivo de ampliar sua presença digital, facilitar o acesso dos clientes aos produtos e serviços e contribuir para a organização dos pedidos e processos de atendimento.

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema web para a Padaria Vitória, desenvolvido como parte das atividades de extensão do curso de Análise e Desenvolvimento de Sistemas da UNIP.

A solução foi criada considerando que a padaria possui recursos limitados para divulgação e alcance de novos clientes. Dessa forma, o sistema busca contribuir para sua presença digital e facilitar o acesso dos clientes às informações, produtos e serviços oferecidos.

A plataforma permite que os clientes consultem produtos, realizem pedidos, escolham formas de entrega e pagamento e acompanhem o andamento de suas compras.

Para os funcionários, o sistema disponibiliza recursos para gerenciamento de produtos e pedidos, atualização de informações e comunicação com os clientes.

---

## Funcionalidades

### Para clientes

* Cadastro e autenticação de usuários;
* Recuperação de senha;
* Edição de perfil;
* Consulta e busca de produtos;
* Organização dos produtos por categorias;
* Cadastro e gerenciamento de endereços;
* Preenchimento de endereço por CEP;
* Carrinho de compras;
* Finalização de pedidos;
* Escolha entre entrega e retirada na loja;
* Seleção da forma de pagamento;
* Utilização de promoções e cupons de desconto;
* Realização de encomendas;
* Acompanhamento do status dos pedidos;
* Histórico de pedidos;
* Recebimento de notificações;
* Avaliação de pedidos;
* Solicitação de atendimento para devoluções;
* Acesso às informações e canais de contato da padaria.

### Para funcionários

* Autenticação de funcionários;
* Cadastro de produtos;
* Gerenciamento de produtos e categorias;
* Controle da disponibilidade dos produtos;
* Visualização e gerenciamento de pedidos;
* Atualização do status dos pedidos;
* Painel administrativo;
* Notificações de novos pedidos;
* Comunicação com clientes;
* Gerenciamento de situações relacionadas à indisponibilidade de produtos.
